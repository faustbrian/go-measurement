package measurement // import "github.com/faustbrian/go-measurement/v3"

Package measurement provides immutable exact logistics quantities with explicit
units, dimensions, conversion policy and arithmetic bounds. Start with New or
Parse using SymbolProfile, then choose ExactConversion or RoundedConversion for
compatible-unit operations.

Decimal arithmetic is owned by github.com/faustbrian/go-math/decimal; core
quantities never convert through binary floating point. The closed unit catalog
uses exact source-defined ratios; loading metres remain semantically distinct
from ordinary lengths. Absolute temperatures can be converted and compared,
but addition/subtraction reject unmodeled temperature intervals. Negative and
zero amounts are allowed in Quantity; logistics constructors separately require
positive dimensions and formula inputs.

Quantity, Dimensions, conversion policies and Profiles can be shared for
concurrent value operations. Pointer decoding methods replace their receiver
only on success and require exclusive caller ownership during mutation.
Context-suffixed operations require a non-nil context, check cancellation before
other arguments and do not retain it. They return no partial result after an
observed error; cancellation does not forcibly interrupt a decimal primitive.
Methods without the suffix use context.Background().

No package introduces cgo, external services or background work. The package
does not infer units/locale, select carrier tariffs, pack cargo or own database
transactions. The adapters/wire package handles bounded JSON/XML codecs;
measurementwire retains the deprecated compatibility facade. Use the bounded XML
parse functions rather than raw encoding/xml unmarshalling.

TYPES

type ConversionContext struct {
	// Has unexported fields.
}
    ConversionContext makes exact versus rounded conversion an explicit caller
    choice. It is an immutable arithmetic policy, not an operation context;
    values can be reused concurrently. Its zero value is invalid. Rounding
    applies at each conversion/division boundary, not once across a composed
    formula.

func ExactConversion() ConversionContext
    ExactConversion returns a policy using go-math defaults that rejects
    non-terminating base-ten quotients with go-math.ErrConversion. Terminating
    results can still exceed resource limits; exactness is not unbounded
    precision.

func RoundedConversion(scale int32, mode decimal.RoundingMode) ConversionContext
    RoundedConversion returns a context that rounds the combined final ratio at
    scale fractional places, before subtracting a target affine offset. Negative
    scales round to powers of ten. Validation occurs when used: invalid scales,
    rounding modes or limits return ErrInvalidContext. Same-unit conversion is a
    no-op and does not quantize; use Quantity.Round for final display scale.

func (c ConversionContext) WithLimits(limits gomath.Limits) ConversionContext
    WithLimits returns a copy using explicit arithmetic resource limits. Zero
    limits select go-math defaults; nonzero limits are validated when used. New
    and explicit Quantity.Round still use their own default admission limits.

type Dimension uint8
    Dimension is a closed physical-dimension identity. Loading metre has a
    distinct semantic identity even though its displayed unit contains metres.

const (
	// Dimensionless identifies ratios and counts with unit one.
	Dimensionless Dimension = iota
	// LengthDimension identifies ordinary lengths, distinct from loading metres.
	LengthDimension
	// AreaDimension identifies squared length.
	AreaDimension
	// VolumeDimension identifies cubed length.
	VolumeDimension
	// MassDimension identifies mass, not gravitational force.
	MassDimension
	// TemperatureDimension identifies absolute temperatures, not intervals.
	TemperatureDimension
	// DensityDimension identifies mass per volume.
	DensityDimension
	// LoadingMetreDimension identifies occupied loading-floor length and
	// does not participate in general derived-dimensional arithmetic.
	LoadingMetreDimension
)
    Supported dimensions form the closed physical ontology.

func (d Dimension) String() string
    String returns the stable dimension name, or Dimension(n) for an unsupported
    identity. The zero Dimension is Dimensionless, not an invalid sentinel.

type Dimensions struct {
	// Has unexported fields.
}
    Dimensions is a rectangular package triple and count retaining each side
    in its original unit. Value operations are immutable and safe to share;
    pointer JSON decoding needs exclusive ownership. Its zero value is not a
    usable package. Formula methods do not orient/pack cargo or select tariffs.

func NewDimensions(length, width, height Quantity, quantity uint64) (Dimensions, error)
    NewDimensions validates three positive length quantities (mixed length units
    are allowed) and quantity in [1, MaxPackageQuantity]. Wrong dimensions match
    ErrDimensionMismatch; nonpositive sides/counts match ErrInvalidQuantity.
    No side is converted or rounded. It returns no partial triple on failure.

func ParseDimensionsXML(data []byte) (Dimensions, error)
    ParseDimensionsXML parses a canonical dimensions document under the same
    byte/token/depth and restricted XML policy as ParseQuantityXML. It validates
    positive length sides and bounded count, preserving original unit metadata.
    Syntax failures match ErrMalformedXML and ErrInvalidQuantity; value failures
    preserve unit/dimension classification. Input is not retained and failure
    returns the zero Dimensions. It performs no transport I/O.

func (d Dimensions) CubicVolume(target Unit, conversion ConversionContext) (Quantity, error)
    CubicVolume returns length multiplied by width and height in target without
    caller cancellation.

func (d Dimensions) CubicVolumeContext(
	ctx context.Context,
	target Unit,
	conversion ConversionContext,
) (Quantity, error)
    CubicVolumeContext returns length multiplied by width and height in target
    under caller cancellation. Target must be a volume unit. The result is per
    package; use TotalVolumeContext to include count. The policy is applied at
    individual conversion boundaries, not once across the entire formula.

func (d Dimensions) FloorArea(target Unit, conversion ConversionContext) (Quantity, error)
    FloorArea returns length multiplied by width in target without caller
    cancellation.

func (d Dimensions) FloorAreaContext(
	ctx context.Context,
	target Unit,
	conversion ConversionContext,
) (Quantity, error)
    FloorAreaContext returns length multiplied by width in target under caller
    cancellation. Target must be an area unit. This is one package's footprint,
    not multiplied by the package count. Conversion policy applies to operand
    conversions and then the result; it is not a single formula-wide rounding.

func (d Dimensions) Height() Quantity
    Height returns the original immutable height quantity.

func (d Dimensions) Length() Quantity
    Length returns the original immutable length quantity.

func (d Dimensions) LoadingMetres(
	truckWidth TruckWidth,
	stacking StackingFactor,
	conversion ConversionContext,
) (Quantity, error)
    LoadingMetres calculates floor area / truck width / stacking factor and
    multiplies by package quantity. The result has semantic loading-metre
    identity and therefore cannot be added to ordinary lengths accidentally.

func (d Dimensions) LoadingMetresContext(
	ctx context.Context,
	truckWidth TruckWidth,
	stacking StackingFactor,
	conversion ConversionContext,
) (Quantity, error)
    LoadingMetresContext calculates (length * width / truck width / stacking)
    times package quantity in LoadingMetre under caller cancellation.
    It ignores height and uses explicitly constructed positive formula inputs.
    Rounded policy applies separately to conversions and divisions; it does
    not guarantee one final rounding for the entire formula. Carrier rounding
    and orientation are caller policy (MEASUREMENT-DEC-006, carrier snapshots
    2026-08-30).

func (d Dimensions) MarshalJSON() ([]byte, error)
    MarshalJSON encodes every side's value and unit plus package quantity.

func (d Dimensions) MarshalXML(encoder *xml.Encoder, start xml.StartElement) error
    MarshalXML encodes every side's value and unit plus package quantity.
    Encoder must be non-nil and is caller-owned. Empty/default start names
    become dimensions; other roots are honored but are not accepted by
    ParseDimensionsXML.

func (d Dimensions) Quantity() uint64
    Quantity returns the package count.

func (d Dimensions) TotalVolume(target Unit, conversion ConversionContext) (Quantity, error)
    TotalVolume multiplies one package's cubic volume by the package count
    without caller cancellation.

func (d Dimensions) TotalVolumeContext(
	ctx context.Context,
	target Unit,
	conversion ConversionContext,
) (Quantity, error)
    TotalVolumeContext multiplies one package's cubic volume by the package
    count under caller cancellation. CubicVolumeContext converts to target
    before the count is multiplied exactly; no final quantization is added after
    counting.

func (d *Dimensions) UnmarshalJSON(data []byte) error
    UnmarshalJSON decodes and validates a complete dimension triple within
    MaxSerializedBytes, with strict duplicate/unknown-field and trailing-value
    checks. Each side retains its unit. Nil receivers match ErrInvalidQuantity;
    every failure preserves d. Input buffers are not retained.
    The JSON redaction boundary has the same outer-encoding/json caveat as
    Quantity.UnmarshalJSON.

func (d *Dimensions) UnmarshalXML(_ *xml.Decoder, _ xml.StartElement) error
    UnmarshalXML fails closed because encoding/xml invokes this callback only
    after its caller-owned decoder has parsed and allocated the start token.
    Use ParseDimensionsXML for byte-bounded XML input.

func (d Dimensions) Width() Quantity
    Width returns the original immutable width quantity.

type FormatOptions struct {
	// Unit is the required supported target symbol, not an inferred preference.
	Unit Unit
	// Conversion selects unit-conversion arithmetic before display quantization.
	Conversion ConversionContext
	// Scale is the display quantization scale; negative values round to powers of ten.
	Scale int32
	// Rounding is the explicit display mode, independent of conversion rounding.
	Rounding decimal.RoundingMode
	// Separator is inserted literally; it must be valid UTF-8 of at most 16 bytes
	// without carriage return, newline or NUL. Empty text is accepted.
	Separator string
}
    FormatOptions contains every conversion and display decision. No locale or
    preferred unit is inferred.

type Profile struct {
	// Has unexported fields.
}
    Profile is an immutable explicit mapping of accepted unit tokens, safe for
    concurrent resolution. Its zero value resolves no aliases; no default or
    locale policy is inferred.

func NewProfile(aliases map[string]Unit) (Profile, error)
    NewProfile validates and defensively copies an explicit alias-to-unit
    policy. Nil/empty input creates an empty profile. Alias count must not
    exceed MaxProfileAliases; each alias must have 1..MaxAliasBytes bytes
    and identify a supported unit. Alias text is kept exactly, without
    case/whitespace normalization. Callers must not mutate the input map during
    construction.

func SymbolProfile() Profile
    SymbolProfile accepts only canonical unit symbols.

func (p Profile) Resolve(alias string) (Unit, error)
    Resolve resolves exactly one alias without case or locale inference.

type Quantity struct {
	// Has unexported fields.
}
    Quantity is a decimal amount with explicit unit identity. Value operations
    return new values and can run concurrently. Pointer decoder methods mutate
    the receiver and require caller synchronization. The zero value has no unit;
    construct values with New or Parse. Numeric zero/negative amounts are
    allowed; physical validity and business positivity are not inferred from a
    unit.

func MustNew(amount decimal.Decimal, unit Unit) Quantity
    MustNew constructs a trusted quantity and panics with any error returned by
    New, including unknown units and amount resource limits. Use New for input
    requiring returned validation errors.

func New(amount decimal.Decimal, unit Unit) (Quantity, error)
    New validates unit and default go-math amount limits, preserving represented
    scale without rounding or normalization. Unknown units match ErrUnknownUnit;
    amount-limit failures match ErrInvalidQuantity and the go-math cause.
    It does not reject signed/zero amounts or temperatures below absolute zero.

func Parse(input string, profile Profile) (Quantity, error)
    Parse parses decimal amount, ASCII space and exact alias text under profile.
    It rejects surrounding whitespace and text over MaxTextBytes; profiles do
    not infer missing units or canonical aliases. Decimal syntax/resource errors
    wrap ErrInvalidQuantity and the go-math cause; unsupported aliases match
    ErrUnknownUnit. Signed and zero amounts are accepted. Failure returns the
    zero Quantity.

func ParseQuantityXML(data []byte) (Quantity, error)
    ParseQuantityXML parses one canonical quantity XML document within
    MaxSerializedBytes, MaxXMLDepth and MaxXMLTokens. Scalar amounts/units
    obey MaxTextBytes/MaxAliasBytes. Attributes, namespaces, references,
    comments, directives, nested scalars and trailing documents are rejected.
    Only the optional canonical XML 1.0 declaration is accepted. Nil/empty input
    is an error. Syntax failures match ErrMalformedXML and ErrInvalidQuantity;
    value errors preserve unit/dimension classification without echoing input.
    Data is not retained; failure returns the zero Quantity. Bound transport
    reads upstream.

func (q Quantity) Add(other Quantity, conversion ConversionContext) (Quantity, error)
    Add converts other into q's unit and returns their exact sum without caller
    cancellation.

func (q Quantity) AddContext(
	ctx context.Context,
	other Quantity,
	conversion ConversionContext,
) (Quantity, error)
    AddContext converts other into q's unit and returns their exact sum
    under caller cancellation. The conversion may round other first;
    addition itself is exact and retains q's unit. Absolute temperatures return
    ErrAffineArithmetic.

func (q Quantity) Amount() decimal.Decimal
    Amount returns the immutable decimal amount.

func (q Quantity) Clamp(minimum, maximum Quantity, conversion ConversionContext) (Quantity, error)
    Clamp restricts q to an inclusive compatible interval without caller
    cancellation.

func (q Quantity) ClampContext(
	ctx context.Context,
	minimum, maximum Quantity,
	conversion ConversionContext,
) (Quantity, error)
    ClampContext restricts q to an inclusive compatible interval under caller
    cancellation. Both bounds are converted to q's unit first, potentially with
    rounding; a reversed converted interval returns decimal.ErrInvalid.

func (q Quantity) Compare(other Quantity, conversion ConversionContext) (int, error)
    Compare converts other into q's unit and compares numeric amounts without
    caller cancellation.

func (q Quantity) CompareContext(ctx context.Context, other Quantity, conversion ConversionContext) (int, error)
    CompareContext converts other into q's unit and compares numeric amounts
    under caller cancellation. It returns -1, 0 or +1; the comparison reflects
    any rounding used to convert other and is meaningful only when err is nil.

func (q Quantity) Convert(target Unit, conversion ConversionContext) (Quantity, error)
    Convert converts q into target without caller cancellation.

    Use ConvertContext when the operation belongs to a caller-owned context.

func (q Quantity) ConvertContext(
	ctx context.Context,
	target Unit,
	conversion ConversionContext,
) (Quantity, error)
    ConvertContext converts q into target under caller cancellation and
    an explicit conversion policy. Context admission precedes policy/unit
    validation: nil ctx wraps go-math.ErrInvalidArgument, while observed
    cancellation/deadline errors are returned unchanged. Unsupported units
    and dimension mismatches fail without a partial result. A same-unit target
    returns q after policy validation, without quantizing or rechecking amount
    against caller limits. Other conversions round only the combined quotient;
    target affine-offset subtraction follows that boundary and can leave a
    different represented scale.

func (q Quantity) Dimension() (Dimension, error)
    Dimension returns the unit's physical dimension.

func (q Quantity) Divide(other Quantity, conversion ConversionContext) (Quantity, error)
    Divide returns a supported canonical derived quantity without caller
    cancellation.

func (q Quantity) DivideContext(
	ctx context.Context,
	other Quantity,
	conversion ConversionContext,
) (Quantity, error)
    DivideContext returns a supported canonical derived quantity under
    caller cancellation. Operands are separately converted to canonical
    units before the final quotient uses conversion. Division by zero
    matches go-math.ErrDivisionByZero; unmodeled dimensions return
    ErrUnsupportedDimension.

func (q Quantity) Equal(other Quantity, conversion ConversionContext) (bool, error)
    Equal reports numeric equality without caller cancellation.

func (q Quantity) EqualContext(ctx context.Context, other Quantity, conversion ConversionContext) (bool, error)
    EqualContext reports numeric equality after explicit compatible-unit
    conversion under caller cancellation. Rounded conversion can equate
    distinct source amounts; use exact conversion when equality must not discard
    precision.

func (q Quantity) Format(options FormatOptions) (string, error)
    Format converts, rounds, and formats a quantity without caller cancellation.

func (q Quantity) FormatContext(ctx context.Context, options FormatOptions) (string, error)
    FormatContext converts, rounds, and formats a quantity under caller
    cancellation and explicit options. It first performs the chosen unit
    conversion and then independently quantizes for display, so two rounding
    boundaries can occur. Invalid formatting options match ErrInvalidQuantity;
    conversion/quantization errors retain their classifications. Failure returns
    empty text and leaves q unchanged. Output is not canonical parser input when
    Separator differs from a single space.

func (q Quantity) MarshalJSON() ([]byte, error)
    MarshalJSON encodes value and unit metadata with the decimal as a string.

func (q Quantity) MarshalText() ([]byte, error)
    MarshalText returns canonical amount-space-symbol text.

func (q Quantity) MarshalXML(encoder *xml.Encoder, start xml.StartElement) error
    MarshalXML encodes value and unit metadata without numeric narrowing.
    Encoder must be non-nil; its I/O and lifecycle belong to the caller.
    Empty/default start names become quantity; custom names are honored but
    cannot be read by ParseQuantityXML, which requires the canonical root.

func (q Quantity) Multiply(other Quantity, conversion ConversionContext) (Quantity, error)
    Multiply returns a supported canonical derived quantity without caller
    cancellation.

func (q Quantity) MultiplyContext(
	ctx context.Context,
	other Quantity,
	conversion ConversionContext,
) (Quantity, error)
    MultiplyContext returns a supported canonical derived quantity under
    caller cancellation. Operands are converted separately to canonical units
    using conversion, then multiplied exactly. Rounded conversions therefore
    need not preserve exact algebraic identities. Unmodeled results return
    ErrUnsupportedDimension.

func (q Quantity) Round(scale int32, mode decimal.RoundingMode) (Quantity, error)
    Round quantizes q at scale fractional places without caller cancellation.

func (q Quantity) RoundContext(
	ctx context.Context,
	scale int32,
	mode decimal.RoundingMode,
) (Quantity, error)
    RoundContext quantizes q at scale fractional places under caller
    cancellation. Negative scales round to powers of ten; scale/mode and
    resource errors come from go-math. This only quantizes the amount and
    retains the stored unit without validating it, including an absent
    zero-value unit.

func (q *Quantity) Scan(source any) error
    Scan reads lossless JSON text from a SQL driver. Only string/[]byte input
    is accepted; SQL NULL and other types match ErrInvalidQuantity. Byte
    lengths are checked against MaxSerializedBytes before copying; the driver's
    materialization cost is outside this boundary. Nil receivers fail through
    UnmarshalJSON; every error preserves q and successful decoding retains no
    input buffer.

func (q Quantity) String() string
    String returns represented decimal text, one space and the stored symbol.
    It does not validate the unit; the absent zero value therefore renders "0 ".

func (q Quantity) Subtract(other Quantity, conversion ConversionContext) (Quantity, error)
    Subtract converts other into q's unit and returns their exact difference
    without caller cancellation.

func (q Quantity) SubtractContext(
	ctx context.Context,
	other Quantity,
	conversion ConversionContext,
) (Quantity, error)
    SubtractContext converts other into q's unit and returns their exact
    difference under caller cancellation. Other is converted (and may be
    rounded) first; subtraction is exact and retains q's unit. Absolute
    temperatures return ErrAffineArithmetic.

func (q Quantity) Times(count uint64) (Quantity, error)
    Times multiplies an amount by a bounded positive package count without
    caller cancellation.

func (q Quantity) TimesContext(ctx context.Context, count uint64) (Quantity, error)
    TimesContext multiplies an amount by a bounded positive package count under
    caller cancellation. Count must be in [1, MaxPackageQuantity] or return
    ErrInvalidQuantity. It retains the stored unit without validating it and
    uses default arithmetic limits, independent of a ConversionContext.

func (q Quantity) Unit() Unit
    Unit returns the quantity's unit identity.

func (q *Quantity) UnmarshalJSON(data []byte) error
    UnmarshalJSON decodes one quantity object within MaxSerializedBytes,
    rejecting duplicate/unknown fields, trailing values, numeric amounts
    and invalid units or decimals. Nil receivers match ErrInvalidQuantity.
    It replaces q only on complete success and retains no data buffer.
    Returned JSON diagnostics are redacted, but encoding/json may fail before
    calling this method; those outer errors remain caller-owned. Use errors.Is
    for classification.

func (q *Quantity) UnmarshalText(text []byte) error
    UnmarshalText parses canonical text with SymbolProfile. Nil receivers match
    ErrInvalidQuantity. Failure preserves q; successful replacement retains no
    text buffer. It does not accept caller-specific profile aliases.

func (q *Quantity) UnmarshalXML(_ *xml.Decoder, _ xml.StartElement) error
    UnmarshalXML fails closed because encoding/xml invokes this callback only
    after its caller-owned decoder has parsed and allocated the start token.
    Use ParseQuantityXML for byte-bounded XML input.

func (q Quantity) Value() (driver.Value, error)
    Value stores a quantity as lossless JSON text suitable for SQL text or JSON
    columns.

type Unit string
    Unit is a stable catalog symbol. A cast from string does not validate it;
    Dimension and quantity constructors reject unknown symbols with
    ErrUnknownUnit. Symbols are case-sensitive ASCII wire identifiers, not
    localized typography.

package measurementwire // import "github.com/faustbrian/go-measurement/v3/adapters/wire"

Package measurementwire adapts Quantity to bounded wire JSON and XML codecs
while preserving decimal and unit metadata. Start with Encode/Decode and an
explicitly selected Wire v3 format. This package does not infer a format,
own transport I/O or authenticate documents. Calls are stateless and can run
concurrently; payloads must not be mutated during decoding and are not retained.
No cgo, external service or background lifecycle is introduced.

FUNCTIONS

func Decode(payload []byte, format wire.Format, options Options) (measurement.Quantity, error)
    Decode parses exactly one bounded quantity document in an explicitly
    selected JSON/XML format. The returned Quantity does not retain payload.
    Unsupported formats match wire.ErrUnsupportedFormat. Codec size failures
    match wire.ErrSizeLimit; XML core syntax errors match wire.ErrParse and core
    schema/value errors match wire.ErrValidation. JSON follows the selected
    codec classification, with redacted causes and sanitized type-error
    metadata. All errors return the zero Quantity. Bound transport input before
    materializing it.

func Encode(quantity measurement.Quantity, format wire.Format, options Options) ([]byte, error)
    Encode serializes quantity as JSON or XML, preserving decimal text and unit.
    Other formats return an error matching wire.ErrUnsupportedFormat. The byte
    ceiling governs encoding through the selected codec; returned bytes are
    caller-owned. Errors retain Wire v3 classification.


TYPES

type Options struct {
	// MaxBytes is the selected codec's byte ceiling; zero uses its defaults and
	// negative values are invalid. Core decoding still enforces MaxSerializedBytes
	// independently, so a larger codec ceiling does not widen the core schema.
	MaxBytes int64
}
    Options bounds encoded and decoded documents. Zero values retain the
    selected wire codec's defaults. Core decoding independently enforces
    measurement's document ceiling.
